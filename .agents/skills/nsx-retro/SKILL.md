# nsx-retro

Read `references/rules.md` and `specs/memory.md`. Review the current session.

Add a short note only when all are true:
- The finding is unusual and supported by clear evidence.
- It is highly likely to recur and affects the project broadly.
- It gives a future contributor an actionable thing to do or avoid.
- It is not sensitive or confidential.
- It can not be trivially fixed so it does not occur again (in this case just do the fix)

Use the format of `assets/memory.md` and cite evidence. Merge duplicates. Exclude speculation, session summaries, one-off/local issues and facts already documented elsewhere. If uncertain or nothing qualifies, leave `memory.md` unchanged and say so.
