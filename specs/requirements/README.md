# Requirements

Current, confirmed requirements for the implemented M1/M2 Tenon editor. Each requirement has a
stable non-numeric ID, an EARS statement, a rationale, a fit criterion, and evidence links.

| Feature | Requirements | File |
|---|---|---|
| Exo host integration | `HOST-*` | [feature-exo-host.md](feature-exo-host.md) |
| Project authoring | `PROJECT-*` | [feature-project-authoring.md](feature-project-authoring.md) |
| Schema authoring | `SCHEMA-*` | [feature-schema-authoring.md](feature-schema-authoring.md) |
| Scene and level authoring | `SCENE-*` | [feature-scene-authoring.md](feature-scene-authoring.md) |
| Editor history | `HISTORY-*` | [feature-editor-history.md](feature-editor-history.md) |
| Scene composition | `COMP-*` | [feature-scene-composition.md](feature-scene-composition.md) |

Proposed or future behavior belongs in `changes/`, not here. M3–M6 are design-only and are
not baseline requirements.
